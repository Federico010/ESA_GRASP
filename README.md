# ESA Academy GRASP — Free-Floating Space Robotics

Public overview of my contribution to the collaborative ESA Academy GRASP project at ESTEC.

## Technical focus

- ROS 2 perception and control for an autonomous free-floating robotic system
- Stereo-vision target localization and trajectory generation using the Generalized Jacobian
- Gazebo and hardware testing, Vicon motion capture, and system verification

The project source repository is private. This overview contains no project code or restricted material.
